# Задачи новичка: проверка «нельзя заблудиться»

Рабочий документ. «Измерено» — прогон `node scripts/e2e/tasks.mjs <папка>` (реальные клики через CDP, снимок на каждом шаге);
«оценка» — разбор интерфейса по коду и снимкам, в этом прогоне не кликалось. Клики считаются без ввода текста.

## а. Первый запуск → проект под ESP32 → мигание (измерено: 6 кликов)
Путь: «Создать проект» → плата в списке → «Далее» → имя → «Создать» (поиск платы — ввод текста, не клик).
- Потеряться можно: после создания открывается пустой шаблон `setup()/loop()`, непонятно, как получить мигание.
- Исправлено: над пустым скетчем полоса «Скетч пока пустой… Вставить «Мигание» / Все примеры» (одним кликом вставляется код с `LED_BUILTIN`; сценарий `s`).
- «Дальше: Проверьте скетч» сразу ведёт к следующему шагу; первый тур объясняет боковую панель, «Дальше», плату и порт.

## б. Arduino Uno в пустой среде, сеть перекрыта (измерено, `tasks2.mjs`: 5 кликов, установка из комплекта около минуты)
Путь: «Создать проект» → ввод «arduino uno» → Uno в списке (карточка внизу сама объясняет: «нужно ядро Arduino AVR… можно установить из комплекта, без интернета: версия 1.8.8, понадобится ~357 МБ») → «Установить из комплекта (без интернета)» → «Далее» → имя → «Создать».
- Понятно: главная кнопка — установка из комплекта, «Скачать из интернета» — вторая; после установки зелёная плашка «Поддержка плат «Arduino AVR» (ядро) установлена — плата готова к работе»; в проекте плата Arduino UNO, «Дальше: Проверьте скетч», подсказка «Вставить «Мигание»».
- Потерь нет. Замечание: в строке списка у платы «нужна поддержка платы» без пояснения, пока плата не выбрана; пояснение появляется при выборе (оставлено).

## в. Распиновка платы и пин светодиода (измерено: 2 клика)
Справочник → «Платы и распиновка». Добавлено: у платы, где в данных справочника пин имеет функцию `LED_BUILTIN` (например, Arduino Uno: D13), над схемой плашка «Встроенный светодиод: D13. В коде — LED_BUILTIN». У плат без подтверждённых данных плашки нет (ничего не выдумывается; сценарий — юнит-тест `ledPin.test.ts`).

## г. ESPUI: элементы, привязка, вставка в скетч (измерено: 10 кликов)
Путь: «ESPUI» → «Надпись» → «Ползунок» → «Связи» → строка «Надпись» → «Показывать значение переменной» → список переменных → `temperature` → «Вставить в скетч» → «Подтвердить и вставить».
- Хорошо: полоса «Шаг 1/2/3 из 3» сама называет следующий элемент («свяжите «Ползунок» с переменной»), плашки «temperature → показывает» / «Не связано с кодом» на холсте.
- Замечание: в диалоге вставки без настроенной сети (SSID) показывается красное «в модели 1 ошибок… скетч не соберётся» с кнопкой «Открыть настройки» — тупика нет, но вставка всё равно возможна; оставлено намеренно (ошибка реальная).

## д. Веб-дизайнер: блоки, экспорт (измерено: 5 кликов)
Путь: «Веб-сайт» → «Кнопка» → «Ползунок» → «Экспорт» (меню: index.html, style.css, app.js, page_bundle.html, web_generated.h, web_sketch.ino, project.json, «Все файлы», «Импорт project.json…»). Полоса контекста подсказывает следующий шаг.
- Потерь нет. Предупреждения («Ошибок нет, предупреждений: 3») кликабельны и ведут в «Проблемы».

## е. Библиотеки: реестр Arduino и GitHub (измерено: 4 клика)
Реестр: «Библиотеки» → поиск → список; без сети поиск возвращал сырой JSON-текст ошибки. Исправлено: «Нет связи с интернетом. Уже установленное работает, а поиск и установка новых библиотек и плат требуют сети…», технический текст — в «Подробности» (`cliError.ts`, тест).
GitHub: «GitHub» → «Загрузить каталог» (в тесте каталог уже был в кэше: 10 450 репозиториев). Полностью офлайн-состояние GitHub-вкладки не проверено: каталог GitHub качается не через arduino-cli и прокси из тестового окружения не затрагивается.
- После установки библиотеки из реестра показывается тост «Добавить #include <Х.h>» (имя заголовка — `provides_includes` из `arduino-cli lib list`, проверено на реальном выводе: ESPUI → `ESPUI.h`; вставка после последнего `#include` или после комментариев в начале; юнит-тесты `libInclude.test.ts`). Установка по сети в тестах не выполнялась.

## ж. Монитор порта и плоттер (измерено: 3 клика)
Путь: вкладка кода → «Монитор порта» / «Плоттер» внизу; без порта кнопка «Выбрать порт».
- Потеряться можно: из вкладок справочника/конструкторов нижней панели нет. Исправлено: «Дальше: Откройте монитор порта» и палитра команд работают отовсюду.

## з. Недавний проект, плата, тема (измерено: 5 кликов)
Путь: «домой» в шапке → «Недавние» → чип платы → Esc → «Настройки» → «Светлая».
- Возврат: «домой» подписан подсказкой «Закрыть проект — вернуться на стартовый экран»; Esc закрывает выбор платы и возвращает фокус на чип.

## Общее, что исправлено в этой волне
- Новая «Справка» (кнопка «i» в шапке и на стартовом экране, команда в палитре Ctrl+Shift+P): как начать, где что находится, горячие клавиши, ссылки на README, репозиторий и Issues (адреса зашиты в main, произвольные ссылки не открываются).
- Первый тур из 5 шагов (разделы, плата и порт, Проверить/Загрузить, «Дальше», справочник и конструкторы): запускается один раз при первом открытии проекта, пропускается кнопкой или Esc, повторяется из «Справки» и палитры; в e2e-режиме (`AVRIDE_E2E=1`) не запускается.
- Все диалоги закрываются по Esc и получают фокус при открытии (`Dialog` в kit).
- Полоса над пустым скетчем с вставкой «Мигание».

## Тупики после ключевых действий
- После «Создать проект»: подсказка над скетчем «Вставить «Мигание»» + «Дальше: Проверьте скетч».
- После установки поддержки плат (из «Платы»): тост «Поддержка плат «…» установлена» с кнопкой «Выбрать плату».
- После успешной загрузки: тост «Скетч загружен на плату» с кнопкой «Открыть монитор порта»; «Дальше» тоже предлагает монитор.
- После ошибки сборки: баннер «что случилось» с кнопкой действия, «Дальше: Исправьте ошибки сборки».
- После установки библиотеки: тост «Добавить #include».

## Тур и Справка на 760 и в светлой теме (просмотрено)
Исправлено: карточка тура закрывала подсвечиваемую боковую панель (на 760) — теперь рядом/под элементом, не перекрывая его; полоса «Скетч пуст…» на 760 сокращена и не вырастает до пяти строк. Справка на 760 читаема (прокрутка внутри окна).

## Не проверено
- Реальная установка библиотеки и тост с `#include` (нужен интернет): проверены данные (`includes`) и функции вставки.
- Ссылки справки не открывались (в тестах нет выхода в браузер).
- Полностью офлайн GitHub-вкладка.
- Нестабильность: в одном прогоне поиск «DHT» без сети оставался в состоянии «Ищу…» 12 секунд, в двух повторных прогонах показывал ошибку за 2 секунды; причина не найдена.
