# Задачи новичка: проверка «нельзя заблудиться»

Рабочий документ. «Измерено» — прогон `node scripts/e2e/tasks.mjs <папка>` (реальные клики через CDP, снимок на каждом шаге);
«оценка» — разбор интерфейса по коду и снимкам, в этом прогоне не кликалось. Клики считаются без ввода текста.

## а. Первый запуск → проект под ESP32 → мигание (измерено: 6 кликов)
Путь: «Создать проект» → плата в списке → «Далее» → имя → «Создать» (поиск платы — ввод текста, не клик).
- Потеряться можно: после создания открывается пустой шаблон `setup()/loop()`, непонятно, как получить мигание.
- Исправлено: над пустым скетчем полоса «Скетч пока пустой… Вставить «Мигание» / Все примеры» (одним кликом вставляется код с `LED_BUILTIN`; сценарий `s`).
- «Дальше: Проверьте скетч» сразу ведёт к следующему шагу; первый тур объясняет боковую панель, «Дальше», плату и порт.

## б. То же для Arduino Uno без поддержки плат (оценка: около 5 кликов)
Путь: «Создать проект» → Uno → карточка в мастере «нужна поддержка платы» с кнопкой «Установить ядро»/«из комплекта без интернета» → «Далее» → «Создать».
- Понятно: ядро объяснено как «поддержка плат» в подсказках; в шапке у платы предупреждение, «Дальше: Установите поддержку платы» ведёт в «Платы».
- Проверено ранее e2e-сценариями l, m (в «полный» набор), здесь не повторялось.

## в. Распиновка платы и пин светодиода (измерено: 2 клика)
Путь: «Справочник» → «Платы и распиновка» (схема платы сверху, слева список плат, фильтр пинов).
- Потеряться можно: из вкладки справочника нижние панели скрыты (рабочая область крупнее); вернуться — кликнуть вкладку кода.
- Подсказка «какой пин у светодиода» в справочнике не выделена: пользователь ищет по фильтру пинов (например, «LED»/«GPIO2»). Не исправлено: данных о светодиоде в данных плат нет, выдумывать нельзя.

## г. Страница в конструкторе ESPUI и вставка в скетч (оценка: 7–9 кликов)
Путь: «ESPUI» → шаблон или элемент из списка → привязка к переменной → «Вставить в скетч» → «Подтвердить и вставить».
- Хорошо: пошаговая заставка, полоса «Шаг 1/2/3 из 3» с крошками, диалог вставки с diff.
- Тупик: нет — если в модели есть ошибка, диалог показывает причину и кнопку «Открыть настройки».

## д. Веб-интерфейс в веб-дизайнере и экспорт (оценка: 4–5 кликов)
Путь: «Веб-сайт» → шаблон или блок → «Экспорт» → пункт. Полоса контекста подсказывает «Шаг 1/2/3».
- На 760 px инспектор — выдвижная панель; исправлено: после снятия выделения она закрывается (раньше закрывала превью).

## е. Библиотека DHT: реестр Arduino и GitHub (оценка: 3 клика и 5 кликов)
Реестр: «Библиотеки» → поиск DHT → «Установить». GitHub: вкладка «GitHub» → «Загрузить каталог» → строка → «Установить».
- Понятно: у пустых состояний есть пояснение и действие. Не хватает: после установки не сказано, какой `#include` добавить (не добавлено — нужны данные библиотек).

## ж. Монитор порта и плоттер (измерено: 3 клика)
Путь: вкладка кода → «Монитор порта» / «Плоттер» внизу; без порта кнопка «Выбрать порт».
- Потеряться можно: из вкладок справочника/конструкторов нижней панели нет. Исправлено: «Дальше: Откройте монитор порта» и палитра команд работают отовсюду.

## з. Недавний проект, плата, тема (измерено: 5 кликов)
Путь: «домой» в шапке → «Недавние» → чип платы → Esc → «Настройки» → «Светлая».
- Возврат: «домой» подписан подсказкой «Закрыть проект — вернуться на стартовый экран»; Esc закрывает выбор платы и возвращает фокус на чип.

## Общее, что исправлено в этой волне
- Новая «Справка» (кнопка «i» в шапке и на стартовом экране, команда в палитре Ctrl+Shift+P): как начать, где что находится, горячие клавиши, ссылки на README, репозиторий и Issues (адреса зашиты в main, произвольные ссылки не открываются).
- Первый тур из 5 шагов (разделы, плата и порт, Проверить/Загрузить, «Дальше», справочник и конструкторы): запускается один раз при первом открытии проекта, пропускается кнопкой или Esc, повторяется из «Справки» и палитры; в e2e-режиме (`AVRIDE_E2E=1`) не запускается.
- Все диалоги закрываются по Esc и получают фокус при открытии (`Dialog` в kit).
- Полоса над пустым скетчем с вставкой «Мигание».
