# UX-аудит (рабочий документ)

Основа: снимки `shots.mjs` (1280 и 760, тёмная/светлая), разбор кода shell/. Серьёзность: В — высокая, С — средняя, Н — низкая.

## Сценарии новичка

«Первый запуск → проект → плата → скетч → проверить → загрузить → монитор»
- Старт и мастер понятны (две карточки, шаги «Плата → Проект»). Хорошо.
- В редакторе нет ответа на вопрос «что дальше?»: нужно самому догадаться, что порядок — плата → порт → Проверить → Загрузить → Монитор.
- Монитор порта спрятан во вкладке нижней панели; о нём ничего не подсказывает после успешной загрузки.

«ESPUI → вставить в скетч»: внутри конструктора есть мастер из трёх шагов (хорошо), но найти сам конструктор можно только по значку без подписи.

«Распиновка платы»: «Справочник» → «Платы и распиновка» — не очевидно из значка-книжки.

«Поставить ядро/библиотеку»: два значка (чип и стопка книг) без подписей; при отсутствии ядра предупреждение есть в шапке (значок), но без прямой кнопки.
