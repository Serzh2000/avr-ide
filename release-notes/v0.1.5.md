## Что нового

- **Мастер «Страница для устройства».** Веб-страницу для платы теперь можно сделать по шагам в одном окне, без редактора блоков и кода. Мастер ведёт за руку: название и готовая идея («Свет и розетки», «Мотор или сервопривод», «Метеостанция», «Сигнализация») → что будет на странице → куда подключить каждый элемент → Wi‑Fi → цвет и тема → готово. К любому шагу можно вернуться.
- **Подсказки про пины.** Мастер сам предлагает безопасные пины и помечает те, которые лучше не трогать (загрузочные, TX/RX). Предупреждает, если пин уже занят или не подходит — например, ползунку нужен пин с ШИМ.
- **Живое превью.** На шагах оформления и итога видно, как будет выглядеть страница.
- **«Подключить к скетчу».** В конце мастер сам дописывает в скетч нужные строки. Ответы сохраняются, кнопка «Мастер» откроет их снова. Полный редактор страниц остался для тех, кому нужно больше.

## Загрузка

- **Setup** — установщик Windows x64. Поддержка Arduino AVR и ESP8266 доступна из комплекта без интернета.
- **Portable** — запуск без установки. Поддержка ESP32 поставляется отдельно от приложения.

## Проверка подлинности

- Тег `v0.1.5` и коммиты подписаны (значок «Verified»).
- Файлы собраны в GitHub Actions и имеют подтверждение происхождения: `gh attestation verify <файл> --repo Serzh2000/avr-ide`.
- `SHA256SUMS.txt` позволяет проверить целостность загрузки.

**Предварительный релиз. Файлы не подписаны сертификатом Windows:** SmartScreen может показать предупреждение о неизвестном издателе.
