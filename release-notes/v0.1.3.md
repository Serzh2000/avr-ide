## Что исправлено

- **Сборка страниц с ESPUI и ESP Async WebServer после обновления.** Если в папке библиотек оставалась старая AsyncTCP 1.x (например, после версии 0.1.0 или Arduino IDE), сборка падала с ошибкой `passing 'const AsyncServer' as 'this' argument discards qualifiers`. Теперь IDE при сборке и загрузке сама закрепляет актуальные версии сетевых библиотек, а если стоит только старая — ставит актуальную из встроенного пакета.
- **Примеры в справочнике библиотек открываются.** Кнопка «Открыть» показывает пример во вкладке предпросмотра, оттуда — «Открыть как проект». «В папке» показывает файл в проводнике.

## Что нового

- В справочнике «Библиотеки» можно посмотреть функции, классы и примеры любой установленной библиотеки, а не только подключённых в скетче.

## Загрузка

- **Setup** — установщик Windows x64. Поддержка Arduino AVR и ESP8266 доступна из комплекта без интернета.
- **Portable** — запуск без установки. Поддержка ESP32 поставляется отдельно от приложения.

## Проверка подлинности

- Тег `v0.1.3` и коммиты подписаны (значок «Verified»).
- Файлы собраны в GitHub Actions и имеют подтверждение происхождения: `gh attestation verify <файл> --repo Serzh2000/avr-ide`.
- `SHA256SUMS.txt` позволяет проверить целостность загрузки.

**Предварительный релиз. Файлы не подписаны сертификатом Windows:** SmartScreen может показать предупреждение о неизвестном издателе.
